XGift 站点初始化

本页面只在本机尚未初始化时可用。提交后凭据会写入加密保险库，本页面将永久关闭。

1. 初始化密码

部署时生成的一次性口令，用于确认是本人在配置。填错可重试，不影响已保存的内容。

2. X 登录凭据

最省事的做法：在浏览器里打开 x.com，从开发者工具把 Cookie 整串复制过来，粘进下面这个框， 会自动拆出 auth_token 与 ct0。也可以按 JSON 形式粘贴（见下）。

3. 支付卡

卡号、有效期、CVC 会做 Luhn 与过期校验，不合法会整批拒绝。

4. Stripe 与套餐

5. 出站网络

默认直连；若上游需要代理，可粘贴已导出的 sing-box 配置 JSON。

6. 管理后台密码

管理后台使用 HTTP Basic Auth，用户名固定为 admin。至少 32 个字符。

凭据加密后存入本机保险库，不会随响应回传。
